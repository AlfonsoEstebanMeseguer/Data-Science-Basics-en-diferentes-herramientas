# Data Science Basics en diferentes herramientas
Este proyecto es simplemente una recopilación de ejercicios(o proyectos) muy sencillos de data science (limpieza de datos, etl, consultas, monitorio o representación de datos, por nombrar un poco) en diferentes herramientas de uso profesional a la orden del día como pueden ser: Excel, Tableau, Power BI, Pyhton, etc. El objetivo es interiorizar un poco las distintas aptitudes y funcionalidades de estas herramientas. Próximamente R, Azure, AWS, Databricks
